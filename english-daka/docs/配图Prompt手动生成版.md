# 配图 Prompt 手动生成版

本文件由《配图 Prompt 清单》展开生成，包含编号 001–116 的完整提示词。每个代码块都可以单独复制到 ChatGPT 使用，不需要再手动拼接统一风格前缀。

## 使用方法

1. 建议在同一个 ChatGPT 会话中连续生成，以提高画风一致性。
2. 如需最大程度复刻现有风格，可在会话开始时上传 `lessons/images/street.webp`、`market.webp`、`bus-stop.webp`、`zoo.webp` 四张参考图。
3. 每次只复制一个代码块并生成一张图，不要一次提交多条。
4. 下载后按编号保存为 `001.png`、`002.png`……`116.png`。
5. 字母卡仅允许出现指定的大写和小写字母；其余图片禁止任何文字、字母和数字。
