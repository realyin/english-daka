# 课程制作规范

> 给「拿到线下课的英文原文、要产出一节可上线课程」的人或 Agent 看。
> 照着做，`check_lesson.py` 会全绿；跳过步骤，坑会在孩子面前才炸。
>
> 数据结构的字段说明见 [课程制作指南.md](课程制作指南.md)，这份讲**怎么做**。

---

## 〇、三条铁律

**1. 不替用户选词。** 词表永远来自线下课的原始课件（`lessons/lessons_original/K2/`）。
不要提前造课，不要「补全」字母表，不要替换你觉得更好的词。改「怎么练」可以放手，
改「教什么」要先问用户。

**2. 一张卡 = 一个词条。** 考一考的提问写死是 `"Which one is " + card.word`。
`word` 写成 "more T words"、"face and fingers"、"sort it out" 这种教材页标题，
这张卡就问不出题。原始课件一页四格的，用 `split_panels.py` 切成四张卡。

**一课之内 `word` 不许重复。** 同一个词被课件教了两遍（-an 课里 `man` 一次讲拼合、
一次讲用法，来自两页课件），**不要做成两张卡** —— 学一学里会同一个词连着出现两遍，
看着就是 bug。正确写法是**一张卡挂两问，两问各带自己的图**：

```jsonc
{ "word": "man", "tag": "word", "image": "images/wf-an-1-man.webp",
  "phonics": { ... },
  "dialog": [
    { "q": "How do you read: m — an?", "image": "images/wf-an-1-man.webp", ... },
    { "q": "Who is the man?",          "image": "images/wf-an-2-man.webp", ... }
  ]}
```

只要有任意一问带了 `image`，学一学就不再在卡顶显示大图，改成每问一张。

**3. 音标不能交给 TTS 念。** 写 `/s/` 它会念成字母名 "ess"，咝音根本不存在。
必须用 `/x/` 记号让 `gen_audio.py` 走拼接（详见第三节）。

## 一、五种课型

新课先判断落在哪一型，然后用脚手架生成骨架 —— **不要手写 JSON**，
`seq` 该取几、字段顺序、固定句式都让脚本算：

```bash
python new_lesson.py letter      --badge C --words cat,cup,car
python new_lesson.py word-family --rime ot --words hot,dot,pot
python new_lesson.py cvc         --vowel u --words cub,tub,mud
python new_lesson.py sight-word  --words see,you --extra bird
python new_lesson.py topic --group "主题 Topics" --title "At the Farm · 农场" \
                           --badge 🐄 --words cow,pig,duck
```

| 课型 | seq 段 | 分组 | 卡片构成 | 每卡问数 |
|---|---|---|---|---|
| `letter` 字母 | 1xx | 字母 Letters | 1 张字母卡 + N 张词卡 | 各 2 问 |
| `word-family` 词族 | 2xx | 词族 Word Family | 1 张族卡(`quiz:false`) + N 张词卡(**带拼读面板**) | 族卡 2 问 / 词卡 1 问 |
| `cvc` 拼读 | 3xx | 拼读 Phonics | 全是 CVC 卡(**带拼读面板**) | 1 问 |
| `sight-word` 常见词 | 4xx | 常见词 Sight Words | 虚词卡(`quiz:false`) + 实词卡 | 1 问 |
| `topic` 通用词汇 | 5xx/6xx/7xx | 主题 / 数学 / 科学 | 一词一卡 | 1–2 问 |

段位按**学习路径**排，目录页的组序就是 seq 段序：
1xx 字母 → 2xx 词族 → 3xx 拼读 → 4xx 常见词 → 5xx 主题 → 6xx 数学 → 7xx 科学
（8xx 留给未做的绘本）。先认字母和音，再韵脚成块，再整词拼读。

### letter 字母课

```jsonc
// 字母卡：固定 2 问
{ "word": "letter C", "tag": "letter", "image": "images/c-letter.webp",
  "dialog": [
    { "q": "What's this letter?",              "a": ["It's letter C."],
      "key": ["c"] },
    { "q": "What sound does letter C make?",   "a": ["C makes the sound /k/."],
      "key": ["/k/"] }        // ← 注意是 /k/ 不是 /c/，见第三节
  ]}
// 词卡：固定 2 问
{ "word": "cat", "tag": "word", "image": "images/c-cat.webp",
  "dialog": [
    { "q": "Which letter does cat begin with?", "a": ["Cat begins with letter C."],
      "key": ["c"] },
    { "q": "What sound does cat begin with?",   "a": ["Cat begins with the sound /k/."],
      "key": ["/k/"] }
  ]}
```

### word-family 词族课

族卡讲韵脚，词卡讲拼合。**词卡必须带 `phonics` 拼读面板** —— 词族教的就是拼合，
只让孩子听一句 `"/s/ /at/, sat."` 不如让他点着 `s` `at` 分别听。

```jsonc
{ "word": "-at family", "tag": "CVC", "quiz": false,
  "image": "images/wf-at.webp", "collage": true,   // 是拼图才写 collage
  "dialog": [
    { "q": "What sound does -at make?", "a": ["At makes the sound /at/."],
      "key": ["/at/"] },
    { "q": "What's this family?",       "a": ["It's -at family."],
      "key": ["family"] }
  ]}
{ "word": "sat", "tag": "word", "image": "images/wf-at-sat.webp",
  "phonics": { /* 脚手架自动生成，见下 */ },
  "dialog": [
    { "q": "How do you read: s — at?",
      "a": ["/s/ /at/, sat.", "The cat sat on the mat."],   // 第二条描述这张图
      "key": ["sat"] }
  ]}
```

### cvc 拼读课

全部是带面板的三音词，提问只有一种：`"What word is this?"`（实测 27 问 100% 是它）。

```jsonc
"phonics": {
  "group": "短音 a /æ/ · -an 词族",     // 同 group 的卡在学一学里归到一个分区
  "ipa": "/mæn/",
  "parts": [ {"text":"m","sound":"m","kind":"consonant"},
             {"text":"a","sound":"ae","kind":"vowel"},      // ← 元音要转，见第三节
             {"text":"n","sound":"n","kind":"consonant"} ],
  "onset": {"text":"m","sound":"m"},
  "rime":  {"text":"an","sound":"an"},
  "blend_audio": "audio/phonics/blend-man.mp3"   // gen_phonics.py --blends 生成
}
```

`sound` 必须是 `lessons/phonics.json` 里真有的 key（87 个），否则面板点下去是哑的。
不发音的字母（magic-e 的 e）不写 `sound`。

### sight-word 常见词课

虚词（my / is / to）画不出来，`quiz:false` 挡住「哪一个是 X」。
**但第二条答句必须写成描述画面的句子** —— 听句选图靠它，不写这张卡就白瞎了：

```jsonc
{ "word": "my", "tag": "sight word", "quiz": false,
  "dialog": [{ "q": "What's this sight word?",
               "a": ["It's sight word my.",        // 套话，考一考会跳过
                     "This is my toy."],           // ← 描述画面，听句选图用这条
               "key": ["my"] }]}
```

`QUIZ_FORMULA` 正则会跳过套话答句（`It's sight word …` / `… begins with …` /
`… makes the sound …` / `… family.`），往后找第一条真正描述画面的。

### 有些问天生做不成选择题 → `practice: false`

闯关是三选一，干扰项从**同一课**抽（同类优先，同类不够就掺数字）。所以答案不唯一的
对话式问句会出坏题：

```
"What can chips show?"  →  选项 four / same / ten
```

正确答案是「the same number」，可「Chips can show four」本身就是对的 —— 孩子选 four
没错却被判错。这类问在 `dialog[]` 里标 `"practice": false`：**学一学照常教、照常点读，
只是不进闯关**，它的 key 也不再当别人的干扰项。

`check_lesson.py` 会算出「这一问能抽到几个同类干扰项」，**一个都抽不到**才提醒你
标 `practice: false`。

**只剩一个候选时出二选一，是正当形态，不要标掉。** 大写/小写（`CASE_CHIPS` 只有
两个成员）、只有两个词的小课（eat / drink）都是如此 —— 硬凑第三个只能从别的类里
抓，凑出「big / small / seven」这种跨类噪音，比二选一更糟。

> 踩过的坑：批量标记时写成「候选 < 2 就标」，而每标掉一个又会让普通名词池更小，
> 于是连锁清空 —— 87 问被标掉，实际只该标 29 问，两节课整个没题可闯。
> 批量处理这类规则时，**改完要回头查有没有整课变成 0 问**。

两个开关管的不是一回事：

| 字段 | 层级 | 挡住 | 保留 |
|---|---|---|---|
| `quiz: false` | 卡 | 考一考的「哪一个是 X」 | 学一学、闯关、听句选图 |
| `practice: false` | 问 | 闯关的三选一 | 学一学、考一考 |

### topic 通用词汇课

主题 / 数学 / 科学共用。句式最自由，但**从下面的句式表里选**，别自由发挥。

## 二、提问句式表

从现有 29 课 332 问归纳。**优先用表里的句式**；表里没有再自己写，
写完记得它会被童声(Ana)念出来，句子要短、要具体。

| 场景 | 句式 | 答句 | key |
|---|---|---|---|
| 认字母 | `What's this letter?` | `It's letter C.` | `c` |
| 字母发音 | `What sound does letter C make?` | `C makes the sound /k/.` | `/k/` |
| 首字母 | `Which letter does cat begin with?` | `Cat begins with letter C.` | `c` |
| 首音 | `What sound does cat begin with?` | `Cat begins with the sound /k/.` | `/k/` |
| 尾音 | `What sound does bed end with?` | `Bed ends with the sound /d/.` | `/d/` |
| 韵脚发音 | `What sound does -at make?` | `At makes the sound /at/.` | `/at/` |
| 认词族 | `What's this family?` | `It's -at family.` | `family` |
| 拼合（韵脚） | `How do you read: s — at?` | `/s/ /at/, sat.` + 例句 | `sat` |
| 拼合（三音） | `How do you read h, i, t?` | `/h/ /i/ /t/, hit.` + 例句 | `hit` |
| 认词（拼读课） | `What word is this?` | `It's man.` | `man` |
| 认常见词 | `What's this sight word?` | `It's sight word my.` + 描述句 | `my` |
| 认物 | `What's this?` / `What's this animal?` / `What's this place?` | `It's a fox.` | `fox` |
| 颜色 | `What color is the dog?` | `The dog is tan.` | `tan` |
| 数数 | `How many apples are there?` | `There are four apples.` | `four` |
| 算式 | `What is 9 minus 1?` | `Nine minus one is eight.` | `eight` |
| 分类 | `Where should the paper go?` | `It goes in the paper bin.` | `paper` |
| 位置 | `Where is the fox?` | `The fox is in the box.` | `in` |

**答句可以有多条**：第一条回答问题，第二条描述画面（听句选图要用）。
`a` 和 `a_cn` 条数必须一致。

## 三、发音：所有特殊实现都在这

这一节是整份文档最容易出错的地方。**音频体系里没有一处是「随便写 TTS 会处理」的。**

### 3.1 音标记号 `/x/` —— 不能让 TTS 念

TTS 遇到 `/s/` 会念字母名 "ess"。`gen_audio.py` 检测到 `/x/` 形状会自动改成**拼接**：
TTS 念文字段 + 插入 `lessons/audio/phonics/` 的纯音。

**记号 → 音素库 key 的映射（`PHONEME_MAP`）**：

| 记号 | 库 key | 记号 | 库 key |
|---|---|---|---|
| `/a/` | `ae` | `/o/` | `aa` |
| `/e/` | `eh` | `/u/` | `ah` |
| `/i/` | `ih` | `/ks/` | `x` |
| `/kw/` | `qu` | 其余 | 记号本身 |

**辅音字母 ≠ 它的音，有三个例外**：

| 字母 | 记号 | 写错的后果 |
|---|---|---|
| C | `/k/` | 写 `/c/` 映射不到库，退回 TTS 念成 "see" |
| Q | `/kw/` | 同上 |
| X | `/ks/` | 同上 |

一字多音（C 也可以发 /s/、G 可以发 /dʒ/）用 `new_lesson.py --sound` 指定。

**两条硬规矩**：
- **音标只能出现在回答句**。提问是童声 Ana、音素库是 Jenny，写在提问里一句话会混音色。
- **不要写 `"C-at, cat."`**。TTS 念成 "see-at"（whisper 都转成 "Seattle"）。
  要写 `"/k/ /at/, cat."`。`check_lesson.py` 和 `gen_audio.py` 都会拦。

**课程标题里写真 IPA，答句和 key 里写字母记号**：

```jsonc
"title": "Letter A · /æ/",                    // 标题：真 IPA
"a": ["A makes the sound /a/."], "key": ["/a/"],   // 答句和 key：字母记号
"a_cn": ["A 发 /æ/ 的音。"]                    // 中文：真 IPA
```

### 3.2 音素库与纯音配方

`lessons/phonics.json` 有 87 个音，由 `gen_phonics.py` 生成。
纯音**不能让 TTS 直接念文本**（会念字母名），每个音有专门配方：

| 配方 | 做法 | 用在 |
|---|---|---|
| `initial` | 合成 "dah"/"bah" 这类载体音节，按能量在元音起头处切掉元音 | 塞音 b/d/g/k/p/t… |
| `sustain` | 直接合成 "sss"/"mmm" 这类可延长音 | s/f/m/n/v/z |
| `second` | 从 "ox" 里取后半段 | x |

**校验重点是「呃」音**：`initial` 必须按 `vowel_onset()` 切在元音起头处，
截固定长度会把整个元音留下来，`/d/` 就变成 "duh"。改动后用 whisper 转录校验 +
人耳抽查，whisper 转成 "Duh"/"Bye" 这类词就是切多了。

### 3.3 拼接的两档停顿

`gen_audio.py` 里 `GAP_MS`=100ms（音与音之间）、`GAP_PUNCT_MS`=620ms（逗号/句号处）。
`"/d/ /a/ /d/, dad."` 拼完三个音要停一拍再说整词，四个停顿等长会听成
"d-a-d-dad" 四个并排的音。

改这两个参数会进 `_phonics` 指纹，重跑任意一课会**自动全量刷新**所有含 `/x/` 的句子。

### 3.4 角色 → 音色

**只在 `gen_audio.py` 的 `ROLES` 表定义**，任何地方不得手写音色：

| 角色 | 音色 | 语速 |
|---|---|---|
| `q` 提问 | Ana（童声） | -15% |
| `a` 回答 | Jenny（成人女声） | -15% |
| `word` 单词点读 | Jenny | -30% |
| `praise` 鼓励语 | Ana | 默认 |

改音色后重跑任意一课，脚本对比 `lessons/audio/voices.json` 会自动刷新该角色的全部音频。

### 3.5 闯关选项也要念出来

孩子还不认字，选项只给文字等于把口语题变成认读题。所以：

- **每个 `key` 必须有点读音频**。普通词走 `audio/words/<slug>.mp3`，
  音标走 `audio/phonics/<库key>.mp3`。
- **key 属于闭合词池的必须同步进池子**（`app.html`）：
  `PHONEME_CHIPS` / `RIME_CHIPS` / `COLOR_CHIPS` / `NUM_CHIPS` /
  `LETTER_CHIPS` / `SHAPE_CHIPS`。
  不在池子里，`chipFamily()` 认不出，干扰项会掉进普通名词池 ——
  出现「What sound does sea begin with?」配 `/s/ / astronaut / fly` 这种送分题。
  `new_lesson.py` 会在生成时提醒，`check_lesson.py` 会报错。

## 四、命名与字段约定

### 4.1 图片命名

**一名三用**：prompt 里的「存为」名 = 卡片 `image` 字段名 = 入库文件名。
不需要编号对照表（`ingest_images.py` 支持语义命名直接入库）。

| 课型 | 命名 | 例 |
|---|---|---|
| 字母 | `<字母>-<词>` | `c-cat` |
| 词族 | `wf-<韵脚>-<词>` | `wf-at-sat` |
| 拼读 | `cvc-<词>` | `cvc-man` |
| 常见词 | `sw-<词>` | `sw-my` |
| 主题 | `<课程slug>-<词>` | `at-the-farm-cow` |

拆图产生的单格图叫 `<拼图名>-<词>.webp`（`split_panels.py` 的约定）。

> **历史坑**：`isCollage()` 曾经靠「同课里有别的图以它的名字加连字符开头」推断拼图，
> 结果 `o-box.webp` 被 `o-box-fox-in.webp` 顶掉、`f-fox` 被 `f-fox-forest` 顶掉……
> 10 张正经的一图一词卡被挡在考一考外面。现已改成**卡片上显式写 `"collage": true`**，
> 命名从此自由。**不要退回按文件名推断。**

### 4.2 字段速查

| 字段 | 谁写 | 说明 |
|---|---|---|
| `seq` / `group` / `badge` / `title` | 脚手架 | 目录页靠它分组排序；**不要用 `num`/`date`**，那是退役写法，会掉进「未分组」分支 |
| `word` / `cn` / `tag` | 人 | `word` 是一个词条，不是页面标题 |
| `image` | 人 | 出图后填；`ingest_images.py` 会打印填哪个 |
| `emoji` | 人 | 没图时的备胎，出图后自动退居二线 |
| `eq` | 人 | 数学算式卡用 `"eq": "9-1"`，渲染彩色数字块。**不要用 keycap emoji** |
| `quiz: false` | 人 | **卡级**。挡住考一考的「哪一个是 X」。虚词卡、拼读串联卡用 |
| `practice: false` | 人 | **问级**（写在 `dialog[]` 里）。挡住闯关的三选一，学一学照常教。给「天生做不成选择题」的问用 —— 见下 |
| `collage: true` | 人 | 这张图画着好几样东西，两种考题都出不来 |
| `phonics` | 脚手架 | 拼读面板；`sound` 必须在音素库里 |
| `key` | 人 | 小写，是**孩子该说出的那个词**。答案是音时写音标：`What sound does sea begin with?` 的 key 是 `["/s/"]` 不是 `["sea"]` |
| `q_audio`/`a_audio`/`quiz_audio`/`word_audio`/`praise_audio` | **脚本** | `gen_audio.py` 回写，**手写会被覆盖** |
| `lessons/index.json` | **脚本** | `gen_audio.py` 维护，勿手改 |

## 五、配图 prompt

`new_lesson.py` 会生成 `docs/prompts/<课程id>.md`，里面每张卡一条待填的 prompt。
补上画面描述即可，**统一风格前缀已经写好了，别改**（改了这一课的画风就和全站不一致）。

写画面描述的要求：

1. **单一主体**，5 岁孩子一眼认出是那个词
2. **不要画出同一课其它卡片的东西** —— 考一考的选项来自同一课，画重了孩子无从分辨。
   踩过的坑：`k2-letter-o` 里 `o-box`（纸箱里的狐狸）和 `o-fox`（纸箱上的狐狸）
   几乎一样，问「Which one is box?」根本答不出；而且这一课还各多出一张
   `o-box-fox-in` / `o-fox-box-on`，跟前两张是同一个场景 —— 考一考可能把两张
   一模一样的图当成两个不同选项。现已改成：关掉那两道词题，两张图各挂到
   「A fox is **in** the box.」/「The fox is **on** a box.」上，变成真正的 in/on 辨析题。

   出完图跑一遍这个，同课选项里长得太像的会现形：

   ```python
   # 对每一课的考一考图池两两算 dhash 汉明距离，≤40/256bit 就是「几乎一样」
   from PIL import Image
   def dhash(p, s=16):
       px = list(Image.open(p).convert("L").resize((s + 1, s)).getdata())
       bits = 0
       for y in range(s):
           for x in range(s):
               bits = (bits << 1) | (px[y * (s + 1) + x] < px[y * (s + 1) + x + 1])
       return bits
   dist = bin(dhash(a) ^ dhash(b)).count("1")
   ```
3. **不要有文字**（前缀里已经写了一串 NO text/letters/words，别删）
4. 拼图（一图多物）只在**确实要教分类**时才用，用了要在卡上写 `"collage": true`

出图后：

```bash

python ingest_images.py <目录> --dry      # 先看会做什么
```

## 七、自检清单

`check_lesson.py` 查这些。**❌ 会让课直接坏掉，必须清零**；⚠ 是约定问题，要有理由才留。

**❌ 错误**

- 顶层缺 `seq`/`group`/`badge`/`title`，或还在用 `num`/`date`
- `seq` 不在该分组的段位里
- 卡片缺 `word`/`cn`/`tag`/`dialog`，或还有「待填」
- `image` 指向的文件不存在
- `a` 和 `a_cn` 条数对不上
- **提问里出现音标记号**（会混音色）
- **音标记号映射不到音素库**（会退回 TTS 念字母名）
- **写了 `"C-at"` 这种字母+韵脚**（TTS 念成 "see-at"）
- `key` 不是小写
- **`key` 是音标但不在 `PHONEME_CHIPS`/`RIME_CHIPS` 里**（干扰项会串味）
- 拼读面板的 `sound` 不在音素库里（点下去是哑的）
- `added` 不是 `YYYY-MM-DD`（课堂日列表按它排序，格式错了整批找不到；没有该字段不算错——存量老卡就没有）
- 跑过音频后：缺 `q_audio`/`a_audio`、`key` 没有点读音频、`blend_audio` 文件不存在

**⚠ 警告**

- `word` 像教材页标题（`and`/`more`/`sort`/`words`…）
- 卡片既没有 `image` 也没有 `eq`/`emoji`
- 标了 `collage` 却没标 `quiz:false`
- `key` 在答句里找不到
- 同课**普通名词** key 重复（音标/字母/数字这类闭合池不算，字母课整课教一个音是设计使然）
- 考一考可用图 < 2（会整栏隐藏）
- 某一问的同类干扰项 < 2（闯关会掺数字凑数，凑出的选项可能本身也说得通）
- 同一课里 `word` 重复（学一学会连着出现两遍）
- 不带参数跑（查全部）时：index.json 的 `days` 课堂日汇总和卡片的 `added` 对不上（跑 `--fix-index` 就地重建）

## 九、多级别（K1/K2/K3/S1/S2/S3）

内容分阶段：K1→K2→K3→S1→S2→S3，**导入永远跟着孩子的进度走**——手里排位
最高的级别就是正在学的（K1 学完才会去学 K2）。

- 每节课顶层必有 `"level": "K1"/"K2"/…`（`check_lesson` 会拦缺失的）。
  课程 id 前缀 = 小写级别（`k1-letter-b`），由 `new_lesson.py --level k1` 写入
- **seq 级内独立编号**（各级都从自己的段位起算），排序键是（级别, seq）。
  组名可以跨级同名（K1/K2 都可以有「字母 Letters」），分组身份 = 级别+组名
- 结构可以不同：K1 的分组不必套 K2 的七个组，`topic` 课型 + 自定义组名即可，
  未知组名只是警告不是错误
- 目录页：多于一个级别时顶部出现 K1|K2 切换器，默认停在当前级别，
  手动选择记在 localStorage；只有一个级别时切换器不渲染
- 配图命名：跨级撞名时新级别加级别前缀（`k1-a-apple`）；同词同风格**有意复用**
  现有图是允许的（`audio/words/` 词库本来就跨课共享）

### 导入已学完的历史内容（重要）

**批量导入必须用 `gen_audio.py --backfill`**（不盖 `added` 课堂日戳）。
直接跑 gen_audio 会把几百张卡盖成"今天上课"，「按课堂复习」的日期弹窗里
会冒出一条"今天的课 · 300 张卡"。

混合复习不需要按级别配置：Leitner 账本自动吸收历史内容——导入的卡全是
"新卡"，非当前级别的新卡**每轮最多渗入 3 张**（当前级别的新卡优先、不限），
答对快速升盒到 7/14 天档自动变稀。账本键是 `课程id:word`，跨级同词是两条账。

## 十、仍缺的字母

字母课停在 11 节（seq 101–111），**仍缺 c e g h j k l p q u v w x y z 共 15 个**。

词族/CVC 课已经在用 c g h j k l p v 的音（cat、hat、log、gum、pot、van、kid），
但**这些字母孩子还没学到**。等线下课上到哪个就补哪个，用户手里有对应材料，
**不要提前批量造课**。
