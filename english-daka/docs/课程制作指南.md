# 课程制作指南

从原始素材（文本 + 图片）到孩子可以打卡学习的课程，完整流程与注意事项。

## 一、项目结构速览

```
english-daka/
├── index.html            课程目录页（分组展示，读 lessons/index.json）
├── app.html              单文件应用：学一学 / 问答闯关 / 考一考
├── theme.css             主题模板：字体、配色、线条阴影 token（两个页面共用）
├── gen_audio.py          课程音频生成（句子/单词/鼓励语/考题），自动更新目录
├── gen_phonics.py        拼读音素公共库生成（87 个纯音 + 拼读串联）
├── add_image.py          配图归一化入库（3:4 竖图 720×960 webp ≤150KB）
├── split_panels.py       聚合拼图拆成一格一图 + 回填 dialog[].image
├── new_lesson.py         新课脚手架（按课型生成骨架 + 配图 prompt + 同步清单）
├── check_lesson.py       课程自检（❌ 清零才能上线）
├── check_dictionary.py   词典自检（课程里长按查不到中文的词）
├── docs/                 文档
└── lessons/
    ├── index.json        课程目录（gen_audio.py 自动维护，勿手改）
    ├── phonics.json      拼读音素公共库（gen_phonics.py 生成）
    ├── dictionary.json   长按查词的中文释义词典（按字母序，新词手动补）
    ├── <课程id>.json     每节课一个文件
    ├── audio/
    │   ├── sentences/<课程id>/   句子音频（课程专属，q-/a- 前缀区分角色）
    │   ├── words/                单词点读（全局池，跨课复用）
    │   ├── praise/               鼓励语（全局）
    │   ├── phonics/              音素纯音 + blend 串联（全局）
    │   └── voices.json           各角色实际音色清单（自动维护）
    ├── images/           课程配图（webp）
    └── lessons_original/ 原始素材（K2/ 按 topic 分层）
```

## 二、课程 JSON 数据结构

```jsonc
{
  "seq": 301,                  // 排序号 topic*100+序号。⚠️ 不要用 "num"/"date"，那是退役写法
  "group": "字母 Letters",     // 目录页分组标题（同组连续显示）
  "badge": "S",                // 目录页徽章文字（≤4字符，可用 emoji）
  "title": "Letter S · /s/",
  "cards": [                   // 卡片列表
    {
      "word": "letter S",      // 词条（显示标题 + 单词点读音频的文本）
      "cn": "字母 S",
      "tag": "letter",         // letter / word / sight word / sign / CVC / number / science
      "image": "images/s-letter.webp",   // 配图（可选，无图用 "emoji" 或 "eq"）
      "quiz": false,           // 可选：把这张卡挡在考一考外（见下）
      "eq": "9-1",             // 数学算式卡（可选）：渲染成彩色数字块，替代 emoji
      "phonics": { ... },      // 拼读面板（可选）：parts/onset/rime，sound 用 phonics.json 的 key
      "dialog": [
        {
          "q": "What's this letter?",       // 问题（童声播放）
          "a": ["It's letter S."],          // 回答句列表（成人女声，可多句）
          "key": ["s"],                     // 闯关判分关键词（=正确答案，用于生成选项）
          "q_cn": "这是什么字母？",
          "a_cn": ["这是字母 S。"],
          "image": "images/xx.webp"         // 该问答的专属配图（可选，覆盖卡片图）
        }
      ]
    }
  ]
}
```

**由 gen_audio.py 自动回写的字段**（手写课程时不要填）：
`q_audio`、`a_audio`、`quiz_audio`、`word_audio`、`praise_audio`、`added`。

**`added`（上课日期戳）**：目录页「按课堂复习」按它把散在多节课里的卡片
按天聚成一批（一次线下课的内容常常横跨字母/常见词/主题好几节课）。
gen_audio.py 只给"既没有 added、也还没生成过音频"的卡盖戳——
也就是这次新加的卡；默认盖当天，**补录昨天的课要加 `--date 2026-08-30`**。
早于这套机制的存量老卡没有戳、不属于任何课堂日，这是有意的（真实上课
日期已不可考，不造假数据）。手工改过 `added`（或删卡/挪卡）后跑
`python3 check_lesson.py --fix-index` 重建 index.json 的 `days` 汇总。

## 三、建课流程

> **完整规范见 [课程制作规范.md](课程制作规范.md)** —— 五种课型模板、提问句式表、
> 发音的全部特殊实现、配图 prompt、自检清单都在那份。这里只是速查。

```bash
# 1. 按课型生成骨架 + 配图 prompt（词表来自线下课件，脚本不替你选词）
python3 new_lesson.py letter --badge C --words cat,cup,car

# 2. 填掉骨架里的「待填」，然后自检
python3 check_lesson.py lessons/<课程id>.json

# 3. 补 docs/prompts/<课程id>.md 的画面描述 → 出图 → 入库
python3 ingest_images.py <图片目录>          # 或 add_image.py 单张

# 4. 生成音频（自动登记目录页；新卡顺带盖上课日期，补录昨天的课加 --date）
python3 gen_audio.py lessons/<课程id>.json
python3 gen_audio.py lessons/<课程id>.json --date 2026-08-30   # 课是昨天上的
# 拼读课 / 词族课追加：python3 gen_phonics.py --blends lessons/<课程id>.json

# 5. 再自检一次 —— 这次连音频一起查，❌ 必须清零
python3 check_lesson.py lessons/<课程id>.json

# 6. 词典自检：新课的词 / 句子里的词长按要能查到中文，缺的补进 lessons/dictionary.json
#    （复数、's、-ing、-ed 会自动折回原形，running/making 也能折回，只补原形即可）
python3 check_dictionary.py lessons/<课程id>.json
```

## 四、图片处理

原始素材常见三种形态，处理方式不同：

| 素材形态 | 处理方式 |
|---|---|
| 等宽多联画报（如 7 栏动物园） | 按列裁切成单卡竖图：`crop_panels.py 图 0.67 名1 名2 ...`（0.67=取每列上部高度比例，裁掉底部文字） |
| 整版海报（布局不规则） | 整图横版入库：`crop_panels.py 图 0 名字` |
| 单图 | `add_image.py 原图 语义名` |
| 聚合拼图（2×2 四格 / 三格并排） | `split_panels.py`：按格切开、补背景成 3:4、回填 `dialog[].image` |

注意事项：

- **命名语义化**：`s-letter.webp`、`math-one.webp`，方便复用与排查。
- **分辨率标准**：竖图 720×960（3:4），横版 960×720，webp ≤150KB。卡通插画这个规格在 2x 屏上够清晰；只有真实照片才考虑升到 960×1280。
- **文本和图片的对应关系只在同一素材文件夹内**，不跨文件夹。
- AI 生成新配图时直接要 3:4 竖图，脚本是居中裁剪不拉伸。

## 五、音频体系（重要）

1. **所有音频按角色查表生成**，角色→音色只在 `gen_audio.py` 的 `ROLES` 一处定义：
   `q`=Ana 童声提问、`a`=Jenny 回答、`word`=Jenny 慢速点读、`praise`=Ana 鼓励。
   **绝不在别处手写音色**，否则会出现一句话混多个音色。
2. **改音色 / 改音素库 / 改拼接停顿后，重跑任意一课即可**：脚本对比
   `audio/voices.json`（角色音色 + `_phonics` 指纹＝音素库内容 + 停顿参数）
   发现变化，自动全量刷新受影响的音频（原地覆盖，JSON 不用动）——音色变了刷
   该角色的全部音频，音素库/停顿变了刷**所有课**里含 `/x/` 的拼接句。
   这三种情况都还要另跑 `gen_phonics.py --blends <课程>` 重建拼读串联。
3. **命名即去重**：单词/鼓励语按文本内容命名（`words/street.mp3`），
   跨课自动复用且点读发音全课程一致；句子按课程分目录（跨课句子复用率实测为 0）。
4. **考一考的提问（"Which one is …?"）也是预生成的**（卡片的 `quiz_audio`），
   不要依赖浏览器 TTS——那是机器人声，只作为音频加载失败的兜底。
5. 音素纯音不能让 TTS 直接念（会念成字母名），`gen_phonics.py` 里每个音都有
   配方（载体词+剪切方式），改配方后用 whisper 校验 + 亲耳抽查。
   **校验重点是"呃"音**：`initial` 配方从 "dah/bah" 里截辅音，必须按能量切在
   元音起头处（`vowel_onset()`）；截固定长度会把整个元音留下来，`/d/` 就成了
   "duh"。whisper 把纯音转成 "Duh"/"Bye" 这种词，就是切多了。
6. **拼读句的节奏由标点决定，不用手工调**：`gen_audio.py` 遇到 `/x/` 记号会把
   句子拆成「TTS 文字段 + 音素库纯音」拼接，断口的停顿分两档——音与音之间
   `GAP_MS`=100ms，**逗号/句号处 `GAP_PUNCT_MS`=620ms**。所以
   `"/d/ /a/ /d/, dad."` 会念成「d·a·d —— dad」：三个音贴在一起才拼得成词，
   然后停一拍再说整词。两档拉不开（比如都是 140ms）就会听成 "d-a-d-dad"
   四个并排的音，孩子不知道最后那个是"拼出来的结果"。

## 六、内容编写注意事项

- **判分关键词 `key`**：就是这道题的"正确答案词"，小写。**同一课内不同题的
  key 尽量不同**，且 key 应当是孩子要说出的核心词（nine / street / monkey），
  不是句子里的虚词。
- **闯关选项会被念出来，而且干扰项同类**：选项 chip 不是纯文本——题目进题自动
  播，选项由孩子点「🔊 听选项」依次朗读并高亮。孩子还不认字，
  选项只给文字等于把口语题变成认读题。两条约束因此变成硬性的：
  - **每个 key 必须有点读音频**。普通词走 `audio/words/<slug>.mp3`（或本课
    `word_audio`），音标走 `audio/phonics/`，且**元音要按 gen_audio.py 的
    `PHONEME_MAP` 转**（/a/→ae、/o/→aa、/i/→ih），按 words/ 拼路径会 404。
  - **颜色/数字/字母/形状的 key 必须在对应词池里**（app.html 的 `COLOR_CHIPS` /
    `NUM_CHIPS` / `LETTER_CHIPS` / `SHAPE_CHIPS`），否则 `chipFamily()` 认不出，
    它会掉进普通名词池，出现「What color is the apple?」配 red / astronaut /
    catch 这种混类选项——孩子不用听懂，看出"另外两个不是一类"就能排除。
    往词池加词前先确认 `audio/words/` 有对应 mp3，没有就先跑 gen_audio.py。
    普通名词的干扰项从**整课**的词里抽（不是本轮 `ROUND_MAX` 抽中的那几问）。
- **答案是"音"的题，key 写音标不写词**：`What sound does sea begin with?`
  的答案是 /s/，key 就写 `["/s/"]`。写成 `["sea"]` 是把题干的词当答案，
  孩子说对了却找不到对应的选项。闯关看到 `/x/` 形状的 key 会自动改从音标池
  抽干扰项（app.html 的 `PHONEME_CHIPS` / `RIME_CHIPS`），出成听音辨音题。
- **拼读题照这个格式写，节奏自动继承**（新增单词不用改任何脚本）：

  ```json
  "q": "How do you read d, a, d?",
  "a": ["/d/ /a/ /d/, dad.", "This is my dad."],
  "key": ["dad"]
  ```

  三条硬约束：① 音写成 `/x/` 记号，元音直接写 `/a/ /o/ /i/`，脚本按
  `PHONEME_MAP` 转成库里的 key（另有 `/ks/`→x、`/kw/`→qu）；② **拼读串和整词
  之间必须有逗号**——「停一拍再说整词」这个节奏就是从这个逗号来的，写成
  `"/d/ /a/ /d/ dad."` 会变回四个等距的音；③ 音标只能出现在回答句（`a`），
  提问句里写音标会用 Ana 童声，和音素库的 Jenny 音色对不上。
  长一点的变体 `"S says /s/, A says /a/, T says /t/, sat."` 同理，每个逗号
  都会自动停一拍。写完跑 `python3 gen_audio.py lessons/<课程>.json` 即可。

  **提问句里的两个部件要用破折号断开**：`"How do you read f and an?"` 这句
  TTS 会一口气念完（实测 2.81s、内部零停顿），`f` 和 `an` 全埋在句子里。
  写成 `"How do you read: f — an?"` → 2.71s、停顿 [300, **670**]。

  两个要点：① **`and` 要去掉**，`and` /ænd/ 和 `an` /æn/ 是近音，黏在一起
  再大的停顿也分不开；② **破折号 ` — ` 在 gen_audio.py 里是真停顿**——TTS
  的句内标点最多只停 ~300ms（逗号、冒号、省略号实测都是这个数，是硬上限），
  不够拿来断拼读部件，所以 `stretch_beat()` 会把 TTS 在破折号处自带的那段
  停顿撑到 `GAP_PUNCT_MS`(620ms)。破折号本身不发声。

  ⚠️ **注意这里是"整句渲染一次再撑长静音"，不是把句子拆成两段分别合成**。
  拆开合成过一版，结果孤立的 `"an?"` 被念成了 **"n"**——TTS 把它当成不定冠词，
  用了弱读形式 /ən/（schwa + n，元音几乎没有音色，听感只剩个 n）。实测：
  孤立 `an` 有声时长 0.35s（一个音节，不是把字母拼出来——`A N` 要 0.74s），
  频谱与 `en` 相似 0.949、与 `Ann` /æn/ 只有 0.733。放回整句、落在句尾问号前
  拿到重音，元音才恢复成饱满的 /æn/。
  **短词的发音取决于句子上下文，所以只能整句渲染。**
  （音素库里 /æn/ 的载体词写的是 `Ann` 不是 `an`，就是为了绕开这一点；
  `at` 实测没有这个问题，库里的 at.mp3 与 cat/hat 的 /æ/ 相似度 0.93/0.89。）
  `stretch_beat()` 只替换静音区间的长度，语音采样一个字节都不碰。
  文本里第 k 个停顿标点对应音频里第 k 段静音，所以破折号前面有几个
  逗号/冒号都能对上。

  ⚠️ **绝不要写成 `"C-at, cat."` 这种「字母-韵脚」的形式**：它不含 `/x/` 记号，
  整句直接交给 TTS，字母会被念成**字母名**——实测 C-at → "see-at"（whisper
  转成 "Seattle"）、M-an → "em-an"、S-at → "ess-at"，正好把「c 发 /k/」这个
  教学点念反了。写成 `"/k/ /at/, cat."`。`gen_audio.py` 的 `lint_lesson()`
  会在合成前扫出这种写法并警告，但它只警告不拦，看到了就改。
  同一个 `lint_lesson()` 也会扫「提问句里的字母后面没标点」这一类。
- **一张卡 = 一个词条 = 一张图**：考一考的提问是 `"Which one is " + card.word`，
  所以卡片的 `word` 必须是孩子要学的那个词。原始课件常常一页四格、四个词共一张
  拼图，直接搬过来 `word` 就成了 "more T words"、"face and fingers"、
  "sort it out" 这种页面标题，问出来没法回答。正确做法是 split_panels.py 切图后
  **按格拆卡**：一个问答 → 一张卡 → 一张单格图 → 一个词。
- 实在拆不动的卡加 `"quiz": false`：拼读串联（"How do you sound out s, a, t?"）、
  "这是什么词族" 这类题本来就无实物可画。这是例外，不是常态。没有
  image/eq/emoji 的卡在选项里只能渲染成空白方块，也自动被排除。
- **考一考有两种问法，虚词卡靠第二种活下来**：
  - `word` 题「哪一个是 X?」——只在卡的 `word` 就是画里那个东西时成立，
    受 `quiz:false` 管。
  - `sent` 题「听一听，说的是哪一张?」——播这一问的 `a_audio`，选图。
    **不受 `quiz:false` 管**，但只认「这一问自己的图」：`dialog[].image`，
    或者整张卡只有一问且该卡可考时的卡片图。
  
  所以 `here` / `is` / `to` / `my` 这类虚词卡的正确做法是 **加 `quiz:false`**：
  画不出来的 `word` 题被挡掉，而它底下每一问的单格图 + 答句音频照样出听句题，
  练的是"听懂整句"而不是"认单词"——对虚词本来就该这么考。
  反过来，残余聚合卡（`sort it out` / `need`）只有一张拼图、没有单格图，
  加了 `quiz:false` 后两种题都出不来，正是要的效果。
- **套话答句不会被出成听句题**：`It's sight word my.` / `Apple begins with
  the sound /a/.` 说的是"这个词"不是画面，对着任何图都成立。app.html 的
  `QUIZ_FORMULA` 会过滤掉。**写课时如果希望某一问能进听句题，答句要描述画面**
  （`I like to sing a song.` ✓ / `It's sight word to.` ✗）。
  一问可以配多条答句，套话在前、描述句在后是好写法——
  `"a": ["It's sight word my.", "This is my toy."]`——学一学两句都念，
  听句题自动挑第一条非套话且已配音的那句（这里是第二句）。
  **描述句必须和这张图对得上**：`sw-too` 原来配的是"两个孩子拿同一个红气球"，
  答句却写 `I like reading too.`，对不上，听句题会变成没法答的题
  （已改成 `I like the balloon too.`）。
- **整版拼图不能当选项，两种题都不出**：app.html 的 `isCollage()` 靠命名约定识别
  ——单格图叫 `<拼图名>-<词>.webp`（`split_panels.py` 定的），同一课里只要有别的图
  以某张图的名字加连字符开头，那张就是被拆过的拼图。所以 **`add_image.py` 入库单格图
  时务必沿用这个命名**，否则拼图认不出来，又会混进选项。
  注意这跟 `quiz:false` 是两回事，别混：
  - `quiz:false` 管的是「这张卡的 `word` 画不出来」（`too` / `here` / `count`），
    它只挡 word 题，**不挡听句题**——这类卡的图是单主体，听句题照样成立。
  - `isCollage()` 管的是「这张图画了好几样东西」（`recycling-sort` / `n-need`），
    两种题都挡。
  早先把两者混在一个判据里出过事故：给 `my`/`like`/`I`/`too` 加上 `quiz:false` 后，
  它们的听句题被连带干掉，整课 0 题、考一考被隐藏。
  整课可用卡不足 2 张时 app.html 会隐藏考一考那一栏——**那是提示该拆卡**。
- **配图没出的卡填 `emoji`**：学一学会把它放大顶在卡片上（和 `eq` 一个待遇），
  闯关和考一考也拿它当图用。出图后补 `image`，emoji 自动退居备胎。
- **每轮抽题上限 `ROUND_MAX = 12`**（app.html）：整课 25 问对 K2 太长，
  而打卡是天天来的，每次随机抽一轮，几天下来自然覆盖全课还不重样。
  所以「一课多少张卡」不必卡死，真正要控制的是单张卡别塞太多问答。
- **一题一卡 vs 多题一卡**：内容零散（数字、算式）适合一题一卡（每题有自己的
  配图/算式）；围绕一个单词的多轮对话适合多题一卡。
- **数字类内容用 `eq` 字段**（如 `"10-1"`），不要用 keycap emoji
  （5️⃣➖ 在 Apple 设备上是灰键帽+粗横杠，很丑且各平台不一致）。
- 中文翻译（`q_cn`/`a_cn`）必须配齐——"中"按钮和跟读提示依赖它。
- 语音识别已从闯关移除（对儿童英语识别太差），闯关是"大声说出答案→点选"，
  不要往回加自由语音判分。
- **改课文之前先看这一问配的是哪张图**。原课件的问题常常是"照着画面问"的，
  只读 JSON 会把图文关系一起改掉。踩过一次：letter T 的
  「Which is taller, a rectangle or a square?」作为普遍命题不成立，我改成了
  「哪个有四条边，三角形还是长方形」，可那一格画的是"高长方形 + 矮正方形"，
  根本没有三角形。正确的修法是把泛指改成特指（a → the，"这个长方形比这个正方形高"），
  命题真了，图也不用重出。
- 原始素材有笔误要修正并记录（例：第 20 课 "four fewer than fix" → six）。

## 七、目录页排序规则

`index.json` 由 gen_audio.py 维护，顺序为：
课号课（`num` 大在前）→ 分组课（`seq` 升序，同 `group` 连续则显示分组标题）→ 旧日期课（新日期在前）。
