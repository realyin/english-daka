# 配图 Prompt 手动生成版 · 补缺篇（117–166）

本文件是《配图 Prompt 清单》第六节的展开版，格式与 001–116 的手动生成版一致，
每个代码块可以直接复制到 ChatGPT，**不需要再拼接统一风格前缀**。

## 使用方法

1. 建议在同一个 ChatGPT 会话里连续生成，画风更一致。
2. 会话开始时可以先上传 `lessons/images/street.webp`、`market.webp`、`zoo.webp` 三张
   现有图作为风格参考，让新图和已有的 116 张对得上。
3. **每次只复制一个代码块，一次生成一张**，不要一次提交多条。
4. 下载后按编号保存为 `117.png`、`118.png`……`166.png`。
5. 全部是**单图一物**，不要出 2×2 四格图 —— 四格图正是前几轮花力气拆掉的东西。
6. 出完丢一个目录给我，`ingest_images.py` 批量入库，我把 `image` 字段写进课程 JSON。

> **垃圾分类配色沿用项目已有约定**：纸=蓝桶、金属=绿桶、塑料=橙桶、玻璃=紫桶、
> 厨余=木质堆肥箱。和已入库的 077–080 一致，不要改颜色，否则孩子学到互相矛盾的对应。
