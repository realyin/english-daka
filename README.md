# 瑞思英语K2打卡 english-daka

给幼儿园 K2 的孩子做的英语每日打卡应用。**纯前端、零构建、零依赖**——
两个 HTML 文件 + 一堆 JSON 和 mp3，起个静态服务器就能跑，平板上打开当天点一课，
听、说、选，三五分钟一轮。

课程内容跟着孩子线下课的进度走，不是通用教材：学到哪个字母就做哪一课。
目前 **29 课 / 259 张卡**，全部配图 + 全程真人音色 TTS 配音。

```
字母 Letters      11 课 / 108 卡    seq 101-111
词族 Word Family   3 课 /  29 卡    seq 201-203
拼读 Phonics       5 课 /  27 卡    seq 301-305
常见词 Sight Words  4 课 /  36 卡    seq 401-404
主题 Topics        2 课 /  11 卡    seq 501-502
数学 Math          3 课 /  33 卡    seq 601-603
科学 Science       1 课 /  15 卡    seq 701
```

分组顺序就是学习路径：先认字母和音 → 韵脚成块 → 整词拼读 → 常见词 → 主题。

## 跑起来

```bash
python3 -m http.server 8123 -d english-daka
```

打开 <http://localhost:8123>。没有构建步骤，改完文件刷新即可。

## 三个模块

- **学一学** — 卡片 + 中英问答对话。点单词点读、长按查词典、点空白播整句。
- **问答闯关** — 听题目 → 孩子**大声说出答案** → 再点选（3 选 1）判分。
  题目进题自动播（孩子还不认字，不出声没法答），选项手动播（认得的词他会伸手就点）。
  答对停在原地不自动翻页，出口是「看答案 / 下一题」。
  > 语音识别做过又拿掉了：对儿童英语的识别率太差，误判比帮助多。判分靠点选。
- **考一考** — 听音选卡，"Which one is …?" 的提问是预生成的音频。

每轮随机抽题，上限 12 题。整课 25 问对 K2 太长，而打卡是天天来的——
几天下来自然覆盖全课。

目录页顶部还有三个复习入口：**混合复习**（全部课程一个池子，Leitner 间隔
调度抽一轮）、**按课堂复习**（挑某一天，把那天线下课学的卡片整套再过一遍——
一次课的内容常散在字母/常见词/主题好几节课里，这个入口按上课日期把它们
聚回一批；日期戳由 gen_audio.py 给新卡自动盖）、**错题本**（错过且还没
练熟的词专练）。三个入口进去都和普通课一样先落在「学一学」。

## 建课脚本

都在 `english-daka/` 下运行。需要 `pip install edge-tts pillow`，
音频拼接还需要系统装 `ffmpeg`。

```bash
python3 new_lesson.py 21 "标题"          # 新课脚手架
python3 gen_audio.py lessons/x.json      # 生成全部音频并回写 JSON;新卡顺带盖
                                         # 上课日期(补录昨天的课加 --date)
python3 gen_phonics.py                   # 重建音素公共库
python3 add_image.py 原图.png 语义名      # 单张配图归一化（webp ≤150KB）
python3 ingest_images.py <目录>          # 批量入库
python3 split_panels.py                  # 聚合拼图按格切成单图
python3 check_dictionary.py              # 课程里长按查不到中文的词
```

音频不是随手合成的，有几条硬约定（细节见 `CLAUDE.md` 和 `docs/`）：

- **角色→音色只在 `gen_audio.py` 的 ROLES 表里定义**（提问 Ana 童声 / 回答 Jenny /
  单词 Jenny 慢速），任何地方不得手写音色，否则一句话里会混音色。
- **音标不能交给 TTS 读**。`"S says /s/"` 直接合成会念成 "ess says ess"——
  咝音根本不存在。脚本遇到 `/x/` 记号自动改为拼接：TTS 念文字段，
  中间插入 `audio/phonics/` 里的纯音。
- **纯音也不能让 TTS 念文本**（会念字母名）。每个音有专门配方，
  辅音从 "dah/bah" 载体音节里按能量切在元音起头处——切多了 `/d/` 就变成 "duh"。
- 改音色或改音素库后重跑任意一课，脚本比对指纹自动全量刷新。
